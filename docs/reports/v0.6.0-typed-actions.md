# v0.6.0 release qualification

Date: 2026-07-29

## Release scope

- Typed, bounded repository reads replace shell-shaped read proposals in the trusted path.
- The runtime state reducer rejects invalid transitions and mismatched approvals.
- PawGate and Claw independently validate the same serialized action and constraints.
- Advice-only sessions retain their concrete numbered plan as durable output.
- Timeline responses wrap, scroll, auto-follow recent activity, and expand by click, Space, or E.
- Streaming retries replace the incomplete attempt instead of concatenating duplicate output.

The successful CI run and signed release artifacts remain upstream release gates.

## External gates

Live golden benchmarks and provider qualification require user-supplied provider credentials or
local provider installations. Linux and Windows behavior is covered by the release build matrix,
but installation on those hosts remains an external platform check. Unavailable or skipped gates
are not represented as successful.

The historical benchmark placeholder was removed because it had no matching `benchmark.json` and
reported a blocked provider run. Its still-relevant external gates remain recorded above and in
`docs/implementation-status.md`.
