# PurrCode v0.8.0

PurrCode v0.8 introduces the local graphical engineering workspace while preserving the exact
durable authorization and isolated-worktree boundaries established in earlier releases.

## Highlights

- Authenticated, loopback-only Studio launched with `purrcode ui`, with daemon credentials confined
  to the server-side shell.
- Durable Workbench for complete conversation output, activity, diffs, validation, and exact event
  evidence.
- Native PTY/ConPTY terminal sessions with bounded replay, tabs, resize, detach, stop, and
  generation-safe human/agent ownership transfer.
- Bounded environment inspection and real version checks for common project toolchains.
- Progressive test orchestration, truthful unavailable states, failure classification, bounded
  repair routing, focused reruns, and evidence-gated completion.

## Qualification

`cargo fmt --check`, workspace clippy with warnings denied, the complete workspace test suite, npm
launcher tests, and npm package dry-run are release gates. Live Ollama, disposable macOS Keychain,
Windows ConPTY execution, and live Azure qualification remain external checks and are not claimed
as passing in this release.
