# PurrCode for VS Code

This extension is a thin client for the authenticated loopback PurrCode daemon. It does not
create an independent agent runtime. Run `purrcode init`, open a Git repository, and use the
PurrCode activity-bar view.

It supports durable task and plan creation, selected-code context with an explicit disclosure
warning, session evidence, approvals, pause/resume/cancel, checkpoints, isolated rollback,
context compaction, per-session model selection, and current-file diff review.
